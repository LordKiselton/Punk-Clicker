Политика конфиденциальности игры «Балаган»

Дата вступления в силу: 2 июля 2026 г.

Игра «Балаган» (далее — «Игра», «мы») уважает вашу конфиденциальность. Настоящая политика описывает, какие данные обрабатываются при использовании Игры на устройствах Android (распространяется через RuStore).

1. Какие данные мы обрабатываем

Сама Игра не собирает и не передаёт персональные данные на наши серверы — у Игры нет собственных серверов. Весь игровой прогресс (сохранения, настройки) хранится локально на вашем устройстве и удаляется вместе с Игрой.

2. Реклама (Яндекс Реклама)

В Игре показывается вознаграждаемая реклама через SDK «Яндекс Реклама» (Yandex Mobile Ads). SDK может автоматически обрабатывать данные, необходимые для подбора и показа рекламы: рекламный идентификатор устройства (Advertising ID), IP-адрес, технические характеристики устройства, данные о взаимодействии с рекламой. Эти данные обрабатывает ООО «Яндекс» в соответствии со своей политикой: yandex.ru/legal/confidential и условиями Yandex Mobile Ads SDK.

3. Аналитика (AppMetrica)

Для улучшения Игры может использоваться сервис аналитики Yandex AppMetrica, который обрабатывает обезличенные данные об использовании приложения (события в игре, модель устройства, версия ОС, страна). Подробнее: условия AppMetrica.

4. Микрофон

Игра может запросить доступ к микрофону для игровой механики «крикни ХОЙ!» — активации режима по голосу. Обработка звука происходит только на устройстве и только в момент, когда открыт экран крика: измеряется лишь громкость сигнала. Звук не записывается, не сохраняется и никуда не передаётся. Разрешение необязательно: без него режим активируется удержанием кнопки.

5. Уведомления

С вашего разрешения Игра показывает локальные уведомления (напоминания о наградах). Они планируются на устройстве и не используют сетевые сервисы. Отключить их можно в настройках Игры или системы.

6. Дети

Игра не собирает персональные данные и не содержит контента, требующего идентификации пользователя. Показ рекламы регулируется политиками ООО «Яндекс».

7. Изменения политики

Актуальная версия политики всегда доступна по этому адресу. При существенных изменениях мы обновим дату в начале документа.
