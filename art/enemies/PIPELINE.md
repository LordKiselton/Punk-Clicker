## Результат, который считаем «классным»

- Один визуальный язык на весь ростер (15 id): Darkest Dungeon **ink** + панк-сказка.
- Силуэт читается на ~120 px; анатомия верная (не chibi, не каша конечностей).
- Юмор паспорта сохранён (гопник / стримерша / цирюльник), без стикер-шума.
- Фон **плоско** `#00FF00` → вырез в PS или скриптом без полупиксельной каймы.
- Старый бой живёт; новые лежат в `v2/` (+ `v2/alpha/`).

## Шаги (строго по порядку)

### 1. Паспорт

Читать/править [passports.md](passports.md) **до** генерации. На тип нужны:

- характер, тело, силуэт, **один** акцентный цвет, 3–5 якорей, запреты;
- «сейчас / на переген» если переделываем существующего;
- отличия от соседей (три орка; тролль ≠ гном ≠ кузнец труппы; крыса-враг ≠ Крыс-союзник).

Не генерировать «из головы», если паспорт пустой — сначала дописать паспорт.

### 2. Кандидатная папка

```
art/enemies/v2/
  .gdignore          # *.png — не в APK
  README.md
  _chroma_key.py     # вырез
  <id>.png           # мастер, chroma
  alpha/<id>.png     # после key
```

Живые `art/enemies/<id>.png` **не перезаписывать** на этом шаге.

### 3. Стилевые якоря (reference_image_paths)

Всегда тащить в генератор (минимум):

| Реф | Зачем |
|---|---|
| `art/heroes/jester.png` | ink, пропорции, панк-сказка |
| `art/enemies/zombie.png` *или* уже принятый `v2/alpha/zombie.png` | якорь вражеского пака |
| `art/enemies/<id>.png` (старый) | сохранить узнаваемость типа |

Опционально: 1–2 кадра труппы v2 (`art/troupe/v2/`), если нужно подтянуть лицо/тушь.

### 4. Промпт — обязательный каркас

Каждый спрайт — **1:1**, один персонаж, полный рост / 3/4.

**CUTOUT (копировать почти дословно):**

- фон только плоский solid chroma green `#00FF00`;
- нет градиента, пола, тени на земле, тумана/частиц **вне** персонажа;
- непрерывный **толстый чёрный ink-контур** по всему силуэту (тело + оружие + крылья/хвост);
- край жёсткий под chroma-key: без soft glow в зелёный, без полупрозрачной каймы.

**STYLE:**

- Darkest Dungeon hand-painted ink, hatching, grimy texture;
- muted limited palette; **один** акцентный цвет из паспорта;
- материалы: кожа, ржавь, кость, тусклая латунь — не RGB-неон, не sci-fi HUD, не голограммы;
- correct anatomy; readable silhouette; no text / UI / watermark / logos / brands;
- no anime, no 3D, no photo, no pixel.

**SUBJECT:** вставить якоря и запреты **из паспорта** этого id (не импровизировать кибер-кашу).

### 5. Генерация

- Инструмент: генерация изображения по описанию + рефы.
- Имя файла мастера: `art/enemies/v2/<id>.png` (после копирования из assets).
- Пачкой по локации или все 15 — ок; стиль-блок CUTOUT/STYLE не урезать.

### 6. Вырез

```bash
python art/enemies/v2/_chroma_key.py
```

Пишет `art/enemies/v2/alpha/<id>.png` (RGBA, жёсткая альфа).  
При необходимости дочистить в Photoshop по chroma-мастеру.

Метрика удачного key: почти нет «мягких» пикселей по краю (`soft≈0` в логе скрипта).

### 7. Приёмка

Чеклист из [v2/README.md](v2/README.md) + паспортный чеклист внизу [passports.md](passports.md).

Смотреть **alpha** на тёмном фоне (или поверх `art/bg/*.png`). Спросить апрув по id / пачке.

### 8. Встройка в бой (только после «ок»)

1. Архив старого: `art/enemies/v1/<id>.png` (если ещё нет v1 — создать папку по аналогии с `art/bg/v1/`).
2. Скопировать принятый `v2/alpha/<id>.png` → `art/enemies/<id>.png`.
3. Godot reimport при необходимости.
4. Не менять `ENEMY_NAMES` / `LOCATION_ENEMIES`, пока не нужны новые id.

## Чего не делать

- Не класть кандидатов сразу в боевой путь.
- Не плодить cyan-неон «чтобы светилось» (банши/техно — бледный/латунный акцент).
- Не добавлять лут у ног, чат-UI, колонки, рой черепов-спутников.
- Не смешивать стили рефов (один прогон = один якорь ink).
- Не пропускать паспорт «потом допишем».

## Перенос на другие ассеты

Тот же каркас (паспорт → chroma `#00FF00` + ink outline → `v2/` + `_chroma_key.py` → приёмка → бой) годится для:

- новых врагов / уникальных боссов;
- full-body героев на арену (если появятся);
- отдельных пропов с прозрачностью.

Портреты труппы (tight crop, parchment) — **другой** пайплайн (`art/troupe/v2/passports.md`), не подменять.

Фоны локаций — свой шаблон (`art/bg/v2/location-passport-template.md`), без chroma-персонажа.
