# Паспорта портретов труппы (v2 candidates)

> Кандидаты для UI. Боевые `art/troupe/*.png` **не трогаем**, пока не примешь.
> Пайплайн: паспорт → генерация → приёмка в панели героев + будущем экране героя.

## Выбор стиля (обратная связь)

| Герой | База стиля |
|---|---|
| `knight`, `jester`, `alchemist` | **новый** v2 (понравились) |
| остальные 7 | **старый** `art/troupe/*.png` (стиль старых) |

Кадр: промежуточная волна `*_v2b` (крупнее старых, без сверх-кропа). Текущие файлы в этой папке = эта итерация.

## Техника UI

| Слот | Размер в игре | Как рисуем |
|---|---|---|
| Строка труппы | `ROW_PORT` 68×68, `keep-aspect-cover` | extreme close-up, лицо ≥ ~55–65% |
| Модалка / экран героя | ~150+ px | тот же tight-кадр |

**Правила читаемости на 68 px**
- не «поясной» bust — паспортный крупный план
- края шляп/ушей могут обрезаться кадром
- 1 сильный силуэт + 1 акцентный цвет
- толстый ink-контур, parchment фон, без текста
- без пикселя, 3D, фото, anime

**Стиль:** Darkest Dungeon character portrait (hand-painted), fantasy-punk балаган.

**Референс:** старые `art/troupe/*.png` + принятые новые knight/jester/alchemist

## 1. knight — Рыцарь

- **Характер:** усталый ветеран, ирония, честь на продажу
- **Лицо:** мужчина 40+, шрамы, тяжёлый взгляд, щетина
- **Силуэт:** сломанный шлем / черепаха-наплечник + рваный плащ
- **Акцент:** выцветший blood-red плащ
- **Запрет:** сияющие латы, героизм «паладина»

## 2. ratrogue — Крыс

- **Характер:** наглый падальщик, уличная смекалка
- **Лицо:** антропоморфная крыса (как сейчас), хитрые глаза, усы
- **Силуэт:** капюшон + большие уши
- **Акцент:** грязная латунь пряжек, тусклое золото каймы
- **Запрет:** милый chibi-крыс, чистый Skaven-клон без панка

## 3. bard — Бард

- **Характер:** гитарист-сказитель, три аккорда и клинок
- **Лицо:** молодой/средний, ухмылка, подводка или грязь на щеках
- **Силуэт:** лохматые волосы + гриф лютни/гитары за плечом
- **Акцент:** выцветший purple / wine + кожа с шипами
- **Запрет:** придворный менестрель в камзоле без панка

## 4. blacksmith — Кузнец

- **Характер:** тяжёлый металл буквально, спокойная сила
- **Лицо:** широкий, сажа, короткая борода/щетина, усталые глаза
- **Силуэт:** фартук + молот на плече / клещи
- **Акцент:** ember-orange искры / раскалённый край
- **Запрет:** гном-карикатура, чистый fantasy dwarf meme

## 5. alchemist — Алхимик

- **Характер:** безумный практик, кровь→золото
- **Лицо:** бледное, ожоги/пятна реагентов, нервный взгляд
- **Силуэт:** колбы / маска / очки с треснувшим стеклом
- **Акцент:** toxic green / acid vial glow (слабо, не neon cyber)
- **Запрет:** белый халат учёного, sci-fi lab

## 6. hunter — Охотник

- **Характер:** молчаливый следопыт, контрактник
- **Лицо:** узкое, спокойное, шрам у глаза, капюшон
- **Силуэт:** капюшон + перо / рог / лук за плечом
- **Акцент:** forest green + кость/серебро амулета
- **Запрет:** эльф-лучник из high fantasy, камуфляж modern

## 7. witch — Ведьма

- **Характер:** жгли трижды — теперь жжёт она
- **Лицо:** женщина, жёсткий взгляд, пепел/шрамы от огня
- **Силуэт:** остроконечная шляпа + перья/кости
- **Акцент:** уголь + тусклая бронза амулетов
- **Запрет:** sexy halloween witch, розовый макияж

## 8. jester — Шут

- **Характер:** тёмный скоморох балагана, хохот как оружие
- **Лицо:** белила/грим, широкая ухмылка, алмазы у глаз
- **Силуэт:** двурогий колпак с бубенцами + жабо
- **Акцент:** blood red + чёрный + тусклое золото бубенцов
- **Запрет:** милый клоун, IT-клоун, Joker-клон 1:1

## 9. berserker — Берсерк

- **Характер:** мош-пит, ярость без щита
- **Лицо:** крик/оскал, дикие глаза, кровь/грязь
- **Силуэт:** растрёпанные волосы / рогатый шлем обломок + топор
- **Акцент:** алый / ржавый металл
- **Запрет:** спокойный викинг-модель, bodybuilder photo

## 10. necromancer — Некромант

- **Характер:** мёртвые — лучшая публика
- **Лицо:** исхудавшее, синеватая бледность, холодная улыбка
- **Силуэт:** капюшон/корона костей + череп-талисман
- **Акцент:** холодный violet / bone ivory
- **Запрет:** lich с зелёным glow-неон, скелет без лица
