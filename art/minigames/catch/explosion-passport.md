# Паспорт: взрыв ловца (бомба в мешке)

**Статус:** три кадра для fail. Боевые файлы: `art/minigames/catch_play/blast_{1,2,3}.png`.  
**Стиль:** тот же ink, что Шут и бомба (толстый контур, 3–4 тона, grit, stipple). Не pixel, не 3D, не VFX-фото. **Немного комикс:** зубчатый starburst, скорость-штрихи — без букв.

**Когда:** бомба проглочена → **0.7 с фитиль** (игра живая: спавн, drag) → Шут пропадает, три кадра + тряска + залп монет → выход (fail, 0 золота).

**Размер в игре:** один квадрат `BLAST_SZ` ≈ **780** (больше `JESTER_H` = 460). Кадр 3 заполняет квадрат почти целиком и **закрывает Шута**.

Связано: [bomb-passport.md](bomb-passport.md) · [passports.md](passports.md) · [MINIGAMES.md](../../../MINIGAMES.md)

---

## Смысл

Это не «урон по HP», это **панчлайн**: мешок съел череп-бомбу, полсекунды тишины, потом балаган сгорает. Читается за кадр на телефоне.

**3 слова:** `огонь · дым · starburst`

---

## Палитра (как бомба + кафтан)

| Роль | Цвет |
|---|---|
| Ядро | parchment / почти-белый, не неон |
| Пламя | gold → orange → **blood crimson** |
| Дым | charcoal, ink-black, грязный серо-бурый край |
| Искры | тусклая латунь, как бубенцы |

Дым **острый**, клочья с зубцами, не ватные облака. Штриховка и точки как на кафтане Шута.

---

## Три кадра (один центр, один силуэт, растёт)

Все 1:1, объект по центру, фон только chroma `#00FF00`. Без персонажа, без бомбы целиком (осколки красной сферы — можно на 2–3), без пола, UI, текста, «BOOM».

| id | Файл | Что на кадре | Доля кадра |
|---|---|---|---|
| 1 | `blast_1.png` | Искра-разрыв: маленький comic-starburst, языки, щепки фитиля. Ещё не гриб. | объект ~35–40% |
| 2 | `blast_2.png` | Середина: шар огня + кольцо дыма, осколки алого металла. | объект ~65–75% |
| 3 | `blast_3.png` | Финал: самый большой. Плотный дым + пламя, **непрозрачный центр**, закрывает всего Шута. | объект ~90–96% |

Кадр 3 обязан быть **массой**, не тонким кольцом с дырой в середине (иначе Шут просветит).

---

## Тайминг (код)

```
бомба в пасти → 0.7 с (Шут на месте, спавн живой)
взрыв: кадр 1→2→3, тряска экрана, пойманные монеты веером из пасти,
дождь на поле — ударной волной от центра
finished fail после ~2.5 с hang (взрыв гаснет, монеты ещё летят)
```

Центр взрыва = центр тела Шута (не пасть мешка).

---

## Запрет

- Буквы, комикс-облака с текстом, «POW».
- Мягкий cartoon-огонь без контура; anime-огненный шар; реалистичный nuke.
- Неон / cyan / magentа.
- Зелёный chroma внутри пламени (дыры).
- Показывать Шута внутри взрыва (он живёт отдельным слоем; кадр 3 его перекрывает).
