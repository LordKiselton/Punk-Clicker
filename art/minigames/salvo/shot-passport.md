# Паспорт: автоогонь ведьмы (залп)

**Статус:** в игре `art/minigames/salvo_play/shot.png`.  
**Геймплей:** автострельба с метлы, 1 урон, не сносит ряд. ХОЙ — другой кадр.  
**Связано:** [hoy-beam-passport.md](hoy-beam-passport.md) · [passports.md](passports.md)

---

## Смысл

Та же зелёная смерть, что ХОЙ, но **пуля**: короткая магическая стрела, не столб на весь экран. Игрок должен читать «тот же яд, другой масштаб».

**3 слова:** `яд · стрела · искра`

---

## Размер

| Где | Что |
|---|---|
| Мастер | Квадрат **1:1**, стрела по центру, остриём **вверх** |
| Объект | ~**40–50% высоты** холста, узкая (древко + корона), много chroma вокруг |
| Игра | ≈ **22×72** px, заметно меньше тайла врага (148) |

Если на 28 px ширины ядро пропадает — кадр провален. Не мини-ХОЙ на пол-экрана.

---

## Палитра (как ХОЙ)

Фон мастера **magenta `#FF00FF`**, не лайм.

| Роль | Цвет |
|---|---|
| Ядро | chartreuse / почти белое |
| Тело | изумруд → виридиан |
| Край | мох + ink |
| Низ | короткий хвост-искра (исток) |
| Верх | жало стрелы, один наконечник |

---

## Силуэт

1. Вертикальная стрела: остриё вверх, хвост вниз.
2. Один ствол, не вилка молнии, не шар зелья, не пуля 9mm.
3. Ink, 3 тона, рваный край — тот же язык, что `hoy_beam.png`, только короче.
4. Без ведьмы, без букв, без янтаря.
