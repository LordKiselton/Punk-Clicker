# Паспорт: ведьма на метле (залп)

**Статус:** idle принят **d1**. Lean_l / lean_r в v1 **нет** — один спрайт `d1_rear.png`, крен кодом не рисуем.  
**Рабочий кадр:** `art/minigames/salvo/candidates/d1_rear.png`.  
**Реф лица/шляпы:** `art/troupe/v3/witch.png`.

---

## Роль в кадре

Вид **сзади**, нижняя треть экрана. Игрок должен узнать её за 0.2 с по **силуэту шляпы + метлы**, не по лицу.

Камера чуть выше, летим **строго следом**. Idle — **чисто спина**, не ¾ вправо: оба плеча симметричны, древко по оси кадра, веник **внизу по центру** (к нам), полёт **от камеры вверх** к горизонту. Не диагональ «улетает вправо».

**3 слова:** `шляпа · метла · наклон`

---

## Силуэт (самое важное)

Читаемый чёрный вырез на фоне неба:

1. **Шляпа** — широкий обод + острый колпак, чуть вправо или влево от вертикали (живой, не линейка). Обод — горизонтальная «шляпка гриба»: самый широкий элемент кадра ведьмы.
2. **Плащ / кафтан** сужается к талии, потом к ступням вдоль метлы — клиновидный хвост, не мешок.
3. **Метла** — прямая диагональ (древко + веник сзади-снизу). Веник = второй якорь: прутья, кость или тряпьё, не IKEA.
4. **Просвет** между ободом шляпы и плечами — шея/волосы. Без просвета голова «приклеена» к плащу.

На телефоне в нижней трети ведьма крупная, но **не шире ~55% экрана**. Игровое поле над ней должно оставаться свободным. Хитбокс позже = узкая зона корпуса, не весь плащ.

Красиво = ясный контур, не детализация корсета. Если на 128 px теряется обод — кадр провален.

## Та же женщина, что в труппе

Спина несёт те же якоря, что портрет:

| Есть | Как видно сзади |
|---|---|
| Остроконечная чёрная шляпа | Обод, пряжки, 1–2 пера / кость на тулье |
| Тёмные растрёпанные волосы | Пряди из-под обода, по лопаткам |
| Чокер с черепом | Застёжка / череп на затылке шеи, мелко |
| Уголь + тусклая бронза | Пряжки, обод амулета — не золото сокровищ |
| Шрамы / пепел | Не рисуем лицо; кожа шеи чуть пепельная |

Тело: взрослая, длинные ноги вдоль метлы (посадка «верхом», не сидит как на стуле). Не chibi, не pin-up.

**Запрет:** sexy halloween, розовый, голая спина, огромные бёдра Nikke, автомат вместо метлы, взгляд в камеру, анфас.

## Позы (три кадра, один крой)

Один костюм, одна метла. **v1 = только idle (d1), без крена.**

| id | Файл | Поза |
|---|---|---|
| `idle` | `candidates/d1_rear.png` | **Чисто сзади.** Метла по оси, плечи равны. |
| `lean_l` / `lean_r` | — | **Не генерим** в v1. |

Наклон живой: локоть, колено, край плаща. Не «весь спрайт rotate».

Idle — старт и отпустил палец (как у ловца). Lean — пока ведём в сторону.

Опционально позже: `win` — рука вверх, метла ровно. Не в первом прогоне.

## Техника кадра

- Портрет **~1024×1280** или квадрат 1024, персонаж в нижних 80% холста, поля по бокам ~10%.
- Фон chroma `#00FF00`. Ступней «на земле» нет — висит в воздухе.
- Толстый ink, 3 тона, без stipple (как труппа v3, не v2-поры).
- Свет сверху-слева + тонкий rim по ободу шляпы и венику (отрыв от неба).

После удачного `idle` он реф для lean.
