# Таб-бар — иконки (бэклог)

Пока в бою: **только текст** полных имён (Труппа / Навыки / Лавка / Сказка), без глифов и без картинок.

Кандидаты силуэтных плиток (idle / active / locked + сет B idle) лежат в [`candidates/`](candidates/).

Выбор / доработка / подключение — отдельно, когда вернёмся к chrome таб-бара.
