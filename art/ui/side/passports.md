# Паспорта иконок сайдбаров

> Слоты арены под HP: слева Афиша, справа Клад + Урон ×2.
> Пайплайн: паспорт → генерация → `art/ui/side/<id>.png` → подключение в `_make_side_slot`.
> Боевой размер в игре: круг **64×64** (`SIDE_PORT`). Рисуем **256×256** (или 512), объект крупно.

---

## Техника (общая для трёх)

| | |
|---|---|
| Холст | квадрат 1:1, объект по центру |
| Фон | плотный тёмный `#1d1525` / почти чёрный — как `PORTRAIT_BG` круга в UI |
| Стиль | Darkest Dungeon / hand-painted ink, fantasy-punk балаган, **не** пиксель, не 3D, не anime, не фото |
| Контур | толстый чёрный ink — силуэт читается на превью 32–64 px |
| Текст / цифры / символы | **запрещены** (`×2`, `!`, `▶`, буквы, монетные номиналы) |
| Композиция | **один** главный объект, без сцены, без персонажей, без кучи мелочи |
| Safe circle | значимое — в центральных ~80% кадра (края круга UI обрежут углы) |

**Приёмка:** узнаётся за 0.3 с на телефоне с 30 см; три иконки не путаются между собой и с золотом/черепом в топбаре.

## 1. `afisha` — Афиша (daily)

- **Файл:** `art/ui/side/afisha.png`
- **Слот:** левый сайдбар, обводка `UI_PURPLE` `#9b64d4`
- **Смысл:** ритуал возврата / «есть подарок дня» — не валюта и не сундук клада
- **Образ:** небольшая **подарочная коробка** с бантом (daily gift). Крышка чуть приоткрыта или бант крупный и читаемый
- **Силуэт-якорь:** квадратная коробка + бант сверху (бант = отличие от сундука)
- **Цвет:** тёмное дерево/картон + акцент пыльной сирени / приглушённый пурпур банта (вторит обводке слота, не неон)
- **3 слова:** `подарок · бант · день`
- **Запрет:** монеты, черепа, календарная сетка, свиток с буквами, куча лута, «!» 

**Почему не афишный плакат:** на 64 px плакат легко превращается в «прямоугольник»; коробка с бантом стабильнее tip-of-tongue «подарок забрать».

## 2. `klad` — Клад (rewarded gold)

- **Файл:** `art/ui/side/klad.png`
- **Кандидаты:** `art/ui/side/klad_candidates/` (`c1_heap`, `c2_spill`, `c3_glow`, `c4_tiers`)
- **Слот:** правый сайдбар верх, обводка `GOLD` `#e0c341`
- **Смысл:** «посмотри ролик → лут», не просто «валюта в кармане»
- **Образ (новая линия):** **куча / стопка золотых монет** — яркая, читаемая на 64–96 px. Не тёмный сундук (старый кадр слишком сливался с `PORTRAIT_BG`).
- **Силуэт-якорь:** треугольная / холмистая масса монет (отличие от **одной** монеты топбара)
- **Цвет:** яркое балаганное золото `#e0c341`…`#f0d060`, толстый ink-контур, тёмный фон `#1d1525`
- **3 слова:** `куча · монеты · золото`
- **Запрет:** одна монета, сундук/замок, мешок «$», play-треугольник, читаемые буквы/цифры на аверсе, неон

**Почему не монета:** одна монета = баланс в шапке; куча = «лут за ролик».  
**Почему не сундук:** на круге сайдбара тёмное дерево пропадало — нужен светлый золотой силуэт.

### Кандидаты (2026-08-27)

| id | Идея | Заметка |
|---|---|---|
| `c1_heap` | хаотичная гора | сильный контраст, ink |
| `c2_spill` | куча с штампом-звездой | яркая; следить за «буквами» штампа |
| `c3_glow` | куча + тёплое свечение | «награда»; чуть глянцевее |
| `c4_tiers` | три столбика | самый простой силуэт на 64 px |

Приёмка → копировать выбранный в `klad.png` (боевой). Старый сундук можно держать как `.bak` рядом.

## 3. `dmg2` — Урон ×2 (boss rewarded)

- **Файл:** `art/ui/side/dmg2.png`
- **Слот:** правый сайдбар под Кладом, обводка `BLOOD` `#b5121b`
- **Смысл:** временный боевой буст на боссе — «сейчас бьёшь жёстче»
- **Образ:** **один клинок** (короткий меч / тесак балагана), остриём вверх или чуть по диагонали; у лезвия **алая энергия / импульс** (язык пламени-крови или ударная вспышка вдоль клинка) — буст читается светом, не надписью
- **Силуэт-якорь:** клинок + гарда + пятно алого свечения (без второго меча и без креста «×»)
- **Цвет:** сталь/сажа + blood-red glow (не розовый, не неон)
- **3 слова:** `меч · алый · импульс`
- **Запрет:** цифра `2`, знак `×`, два скрещённых меча (на 64 px = каша / «икс»), щит, череп

**Почему не голый меч:** без импульса путается с Клинком в Труппе; glow = «усиление сейчас».

## Разведение силуэтов (чек)

| Слот | Форма на 32 px | Акцент |
|---|---|---|
| Афиша | квадрат + бант | пурпур |
| Клад | холм / стопки монет | золото |
| ×2 | вертикальный клинок + красное пятно | кровь |

Если два слота путаются на превью — правим силуэт, не детали.
