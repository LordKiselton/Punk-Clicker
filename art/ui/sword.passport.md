# `sword` — паспорт карточки «Клинок»

> **Принят.** Live: `art/ui/sword.png`. Слот: первая карточка рельса Труппы (`PORTRAIT_H` 150, `KEEP_ASPECT_COVERED`).
> Файл: `art/ui/sword.png`
> Стиль: тот же, что live-портреты `art/troupe/v3/` (плакатные чернила, 3 тона).
> Не путать с иконкой сайдбара `dmg2` (там клинок + алый импульс буста).

---

## 1. Назначение

| | |
|---|---|
| **Роль** | Прокачка тапа: «это твой меч», не герой и не буст |
| **Читаемость** | На 150 px за 0.3 с: **рука в перчатке** + **меч** |
| **Тон** | панк-сказка балагана, не крестоносец, не кибер, не хеви-метал логотип |

**3 слова:** `кожа · кулак · клинок`

---

## 2. Кадр

- Квадрат 1:1. Tight close-up: кисть + гарда + низ клинка + навершие.
- Меч почти вертикально (наклон ≤ ~15° вправо). Остриё **вверх**.
- Гарда-Т **над** кулаком — стык рукоять/гарда/лезвие виден целиком.
- Фон: parchment beige, как у портретов v3. Без рамки, текста, watermark.

**Импорт:** `mipmaps/generate=true`, `size_limit=512`.

---

## 3. Рука (не латы)

- **Правая** кисть, вид чуть сбоку / ¾. Живая кожа пальцев.
- Перчатка: **панковская кожа без пальцев** (fingerless). Тыльная сторона ладони и запястье — тёмная кожа; пальцы голые.
- Застёжка: 1–2 ремня с пряжками / крупные хольнитены. Без латной перчатки, без кольчуги, без наруча-пластины.
- Шипы на перчатке — **не надо** (шипы только на гарде).
- **Анатомия:** большой палец с одной стороны рукояти, четыре пальца с другой, обхватывают цилиндр. Запястье продолжает предплечье, без вывиха и лишних суставов. Пять пальцев, нормальные пропорции.

---

## 4. Меч (классика + шипы на гарде)

**Ось (обязательно):** одна прямая линия  
навершие → рукоять → центр гарды → дол → остриё.  
Клинок **не** ломается в кулаке. Гарда — буква **T**, 90° к оси, оба плеча одной длины.

| Часть | Как |
|---|---|
| Клинок | классический прямой двулезвийный, простой дол, сталь |
| Гарда | прямая перекладина; **панк:** короткий конус-шип на каждом конце + 2–4 пирамидальных шипа/хольнитена на лице гарды |
| Рукоять | обмотка кожей / шнуром, цилиндр |
| Навершие | простой стальной диск или яблоко. Без бубенца, кольца, креста, эмблемы |

Один крупный мазок засохшей крови на клинке — пятно, не брызги.

---

## 5. Стиль (как портреты v3)

- Толстый ink-контур, 3 тона (тень / тон / блик).
- Без stipple, штриховки, пор, микроцарапин, гравировки.
- Палитра: parchment, тёмная кожа, сталь, акцент blood-red (ткань запястья или кровь на клинке).
- Не anime, не 3D, не фото, не неон.

---

## 6. Запрет

- Латная перчатка / гонтлет / кольчуга на кисти
- Тевтонский / железный / любой крест на гарде и навершии
- Бубенец, анархия-A, буквы, гитара, бита, бензопила
- Согнутый клинок, гарда-параллелограмм, «резиновый» металл
- Шесть пальцев, растаявшие суставы, рука слева от оси меча
